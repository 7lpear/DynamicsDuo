# 오목판 카메라 인식

Logitech C920 등 USB 카메라 영상에서 빈 판의 격자선을 자동 검출하고,
원근을 보정하여 9×9, 15×15 또는 19×19 교차점을 표시합니다.
**현재 사용하는 8×8칸 판은 9×9교차점이므로 `--size 9`입니다.**
흰색 양각 격자를 위해 일반 검출 실패 시 국소 대비를 높여 다시 검출합니다.
빈 판과 비교해 각 교차점의 돌 유무와 흑돌·백돌 구분을 실시간 표시합니다.
자동 검출이 어려운 환경에서는 수동 지정도 가능합니다.

## 실행

아래 명령은 DynamicsDuo 저장소 루트에서 시작합니다. 이 도구는 기존 DINO 환경과
OpenCV 버전 요구사항이 다르므로 별도 가상환경에서 실행하세요.

```sh
cd gomoku_vision
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python board_camera.py --camera 0 --size 9 --reset
```

설치가 끝난 뒤에는 이 폴더에서 마지막 명령만 실행하면 됩니다.

Windows PowerShell에서는 이 폴더로 이동한 뒤 다음을 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe board_camera.py --camera 0 --size 9 --reset
```

macOS Python 3.13과 OpenCV 4.14에서 검증했습니다. Windows 실시간 카메라 실행은 미검증입니다.
macOS에서 카메라 권한을 요청하면 허용하세요. 영상이 나오지 않으면
시스템 설정 → 개인정보 보호 및 보안 → 카메라에서 실행한 앱의 권한을 확인하고,
QuickTime 등 카메라를 사용하는 다른 앱을 종료하세요.

## 자동 인식

1. 카메라와 판을 고정하고 빈 판으로 시작합니다. 격자 전체가 보여야 하며,
   카메라가 가능한 수직으로 내려다보도록 설치하세요.
2. 내장 카메라가 보이면 `N`으로 카메라를 전환합니다.
   또는 `--camera 1` 등으로 실행할 수 있습니다.
3. 기본 자동 검출 대상은 9줄, 15줄, 19줄 격자입니다.
   `--size`는 칸 수가 아닌 교차점 수입니다. 8×8칸은 `--size 9`를 사용합니다.
   7/8/9/15/19줄을 명시적으로 지정할 수 있습니다. `G`로 줄 수도 변경할 수 있습니다.
4. 인식되면 자동으로 표시한 격자가 실제 선과 맞는지 확인합니다.
   틀리거나 카메라가 움직였다면 `A` 또는 `R`로 다시 검출합니다.
5. `S`로 보정값과 이미지를 저장하고 `Q` 또는 Esc로 종료합니다.

이전 보정값이 있으면 우선 불러옵니다. 처음부터 자동 검출하려면 `--reset`으로 실행하세요.
자동 검출은 격자의 두 방향 선과 일정한 간격을 찾고, 원근 보정 후 모든 예상 행·열에
실제 선이 있는지 검증합니다. 인식에 실패하면 계속 시도합니다.
손·돌이 격자를 많이 가리거나, 대비가 약하거나, 반사광이 있거나,
기울기가 크면 실패할 수 있습니다. 합성 영상과 실제 C920에서 저장한
흰색 8×8칸 판 영상으로 검출을 확인했습니다. 실시간 안정성은 별도 확인이 필요합니다.

## 수동 보정

1. `M`을 누르면 수동 모드로 전환합니다.
2. 원본 영상에서 **격자의 가장 바깥 교차점**을
   **왼쪽 위 → 오른쪽 위 → 오른쪽 아래 → 왼쪽 아래** 순서로 클릭합니다.
   나무판 테두리를 클릭하지 마세요. 격자의 위쪽에는 조작 안내 문구가
   겹치지 않도록 화면에 여백을 두는 것이 좋습니다.
3. 보정 화면의 초록 선과 노란 점이 실제 격자와 맞는지 확인합니다.
   `U`는 마지막 점 취소, `R`은 네 점 재설정입니다.
4. `S`로 저장합니다. `A`로 자동 모드로 돌아갈 수 있습니다.

## 실시간 돌 유무 확인

1. 격자가 실제 판과 맞는지 확인합니다.
2. **돌을 모두 치운 뒤 `B`**를 누르고 손을 빼세요.
   안정된 화면에서 12프레임을 수집해 빈 판 기준을 만듭니다.
3. 돌을 한 개 놓고 손을 빼세요. 움직임이 줄고 변화가 유지되면
   **원본 카메라 창과 보정 창 양쪽**에 원과 좌표(예: E5)를 표시합니다.
   원본 창 아래 상태 영역의 `Detected: 2 | D4:W, G6:B`처럼 인식 개수와 좌표·색도 확인하세요.
   `B`는 흑돌, `W`는 백돌, `?`는 돌이 있으나 색 판별이 불확실한 상태입니다.
   돌을 치우면 표시도 사라집니다. `PAUSED`이면 보류 중이며 이전 결과를 보여줍니다.
4. `S`로 이미지를 저장하면 돌 유무 행렬과 최근 추가·제거 기록도 JSON으로 저장합니다.
   `occupancy`는 기존과 같이 0=빈자리, 1=점유 추정입니다.
   색을 포함하는 `board` 행렬은 0=빈자리, 1=흑돌, 2=백돌, 3=색 불확실입니다.
   추가·제거·색 변경 기록에는 `color`가 포함됩니다.

프로그램 시작 시 빈 판 기준까지 자동 수집하려면 **실제 판을 비운 상태에서** 실행하세요.

```sh
.venv/bin/python board_camera.py --camera 0 --size 9 --reset --capture-empty
```

기준 영상은 실행 중 메모리에 유지합니다. 재실행하거나 격자를 다시 잡으면 `B`로
빈 판 기준을 다시 수집해야 합니다. `B`를 다시 누르면 현재 인식 기록을 초기화합니다.
카메라나 판이 움직였다면 `A`로 격자를 다시 잡은 뒤 돌을 모두 치우고 `B`를 누르세요.

이 기능은 초기 변화 검출 방식입니다. 손·큰 그림자처럼 넓은 변화가 있으면
기존 상태를 유지하며 판정을 보류합니다. 흰 판의 흰 돌은 대비 보정 후
원형 테두리를 찾고, 빈 판과 비교해 새로 생긴 경계인지 확인합니다.
실제 흰 돌 영상에서 D4 검출과 돌 제거 후 빈자리 복귀를 확인했습니다.
안정된 작은 가림이나 국소 그림자는 돌로 오인할 수 있고, 대비가 매우 약하거나
돌 크기가 예상 범위와 다르면 놓칠 수 있습니다.
색은 그림자를 피한 돌 중심부 밝기를 빈 판의 같은 위치와 비교해 분류합니다.
전체 노출 변화를 보정하며, 중간 밝기나 어두운 영상에서는 불확실로 처리합니다.
색 변화도 일정 시간 유지되어야 확정합니다. 실제 영상에서 D4 백돌·G6 흑돌을
동시에 구분했으며 반사광·어두운 조명·불확실 색·색 교체를 합성 영상으로 검증했습니다.
차례 검증은 아직 없습니다. 판을 움직이면 좌표가 달라지므로 `A`와 `B`로 다시 설정하세요.

문제가 생기면 `D`로 현재 영상·보정 영상·인식 상태를 `diagnostics/`에 저장하세요.
판정 보류 사유, 교차점별 변화 비율, 원형 경계 검출 결과가 포함됩니다.
빈 판 기준 수집 시에도 진단용 기준 영상과 좌표를 저장합니다.
카메라와 판이 전혀 움직이지 않았다면 `--resume-baseline`으로 저장한 진단용
빈 판 기준과 좌표를 함께 복원할 수 있습니다. 이때 돌을 다시 치울 필요는 없습니다.
움직였다면 복원하지 말고 `A`와 `B`로 다시 설정하세요.

보정값은 `calibration.json`, 원본·보정·격자 이미지는 `captures/`에 저장됩니다.
보정값은 다음 실행에서 불러옵니다. 카메라나 판이 움직였다면 `A`로 다시 검출하세요.
네 점 원근 보정은 렌즈 왜곡이나 판의 휘어짐을 보정하지 않습니다.
중앙과 가장자리에서 격자가 모두 맞는지 확인하세요.

```sh
.venv/bin/python board_camera.py --camera 1 --size 19 --reset
```
